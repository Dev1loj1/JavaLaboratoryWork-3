# Лабораторная работа № 3 — вариант 1 «Зоопарк»

Программа рассчитывает суточный рацион слона, попугая и пингвина, сортирует животных по количеству корма и формирует программу выступлений с участием ростовой куклы.

Требуется JDK 17 или новее. Главный класс — `Main`. Тесты JUnit 5 запускаются командой `mvn test`.
